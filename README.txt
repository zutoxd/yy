PBO PERTEMUAN 3 - CRUD DATA MAHASISWA (PHP + ARRAY SESSION)

1. Jalankan Apache di XAMPP (PHP 8.0 atau lebih baru).
2. Salin ketiga file PHP ke C:\xampp\htdocs\pbo_php\pertemuan_03\
3. Buka http://localhost/pbo_php/pertemuan_03/
4. Uji Tambah, Tampil, Edit, dan Hapus.
5. Buka Mahasiswa.php dan DataMahasiswa.php untuk mengenali class, object, property, constructor, method, $this, dan ->.

Data disimpan sebagai array object di $_SESSION['mahasiswa'], bukan database.
Tidak ditujukan untuk aplikasi produksi: belum menggunakan autentikasi, CSRF token, atau penyimpanan permanen.
